About Dashboard

Dashboard is a lightweight self-hosted web application for organising and launching your services, apps and bookmarks. It provides a clean, responsive interface with live API monitoring, a built-in terminal console and AI integration.

Key Features

App & Category Management

  • Full CRUD for applications and categories
  • Drag-and-drop sort order
  • Bulk category assignment
  • Custom icons (upload or URL)
  • Export & import as JSON

Live API Monitoring

  • Per-app API URLs
  • Configurable poll intervals
  • Live stats on app tiles
  • Alert keyword detection
  • Visual warning/danger badges

Quake-style Terminal

  • Hotkey-activated drop-down console
  • Command shortcuts & history
  • Custom HTTP requests with jq
  • Saved command management
  • Fully customisable appearance

AI / Ollama Integration

  • Ollama server integration
  • Model selector with auto-fetch
  • Custom system prompts
  • Single-question & chat modes
  • Configurable chat history

UI & Appearance

  • Dark theme with accent colors
  • Custom background images
  • Collapsible navigation bar
  • Configurable search provider
  • Responsive design
